# Ndiaga Tech – Boutique en ligne

Boutique en ligne fictive de téléphones et d'accessoires (marché Sandaga, Dakar). Projet pédagogique réalisé pour la formation Sunu Code – Développement Web.

## Contenu

- **Site public** : accueil, catalogue, panier et commande
- **Espace de gestion** : connexion, tableau de bord, produits, commandes
- **Fiche produit** en PHP (`produit.php`)

## Technologies

HTML, Bootstrap 5.3, PHP, XAMPP

## Lancer le projet

1. Copier le dossier `ndiagatech` dans le dossier `htdocs` de XAMPP.
2. Démarrer Apache depuis XAMPP.
3. Ouvrir `http://localhost/ndiagatech/` dans le navigateur.
